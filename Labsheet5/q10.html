Apache .htaccess Python CGI Handler Directives

Seamless Python Web Execution

1. Content of the configured .htaccess file:

# Enable CGI execution permissions
Options +ExecCGI +FollowSymLinks

# Register .py extensions to be handled as CGI scripts
AddHandler cgi-script .py

# Set default directory index
DirectoryIndex index.py index.html

# Prevent direct downloads of sensitive log & database files
<FilesMatch "\.(log|sql|ini|env)$">
    Require all denied
</FilesMatch>

2. Requirements in Apache's main httpd.conf:

Ensure that AllowOverride allows Options and FileInfo for this directory:

<Directory "E:/webDesigning">
    AllowOverride All
    Require all granted
</Directory>
