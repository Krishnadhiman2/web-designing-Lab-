Python Virtual Environment (venv) & Apache Integration

Isolated Dependency Management

Step 1: Create and Activate Virtual Environment

# In terminal, navigate to project directory
cd E:\webDesigning\Labsheet5

# Create virtual environment
python -m venv myenv

# Activate virtual environment on Windows
myenv\Scripts\activate

# Install project dependencies inside venv
pip install mysql-connector-python PyMySQL sqlalchemy

Step 2: Point Apache / mod_wsgi to Virtual Environment

In Apache's httpd.conf or VirtualHost configuration:

# WSGI Daemon Mode using Virtual Environment python-home:
WSGIDaemonProcess mywebapp python-home="E:/webDesigning/Labsheet5/myenv" python-path="E:/webDesigning/Labsheet5"
WSGIProcessGroup mywebapp
WSGIScriptAlias / "E:/webDesigning/Labsheet5/wsgi.py"

Step 3: Direct CGI Shebang to Virtual Environment Python Executable

For standard CGI scripts, point the first shebang line directly to the venv binary:

#!E:/webDesigning/Labsheet5/myenv/Scripts/python.exe
# This guarantees scripts run with isolated libraries installed in myenv
