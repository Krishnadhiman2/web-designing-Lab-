Step-by-Step Guide: How to Push Code to GitHub

  1. Open your project folder in the terminal or command prompt.
  2. Initialize a new Git repository using git init.
  3. Stage all files for tracking using git add ..
  4. Commit the staged changes using git commit -m "Initial commit".
  5. Link the local repository with your GitHub repository using git remote add origin <URL>.
  6. Push the committed changes to GitHub with git push -u origin main.
