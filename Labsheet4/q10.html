Apache Virtual Host Configuration Guide

Target Domain: http://collegeweb.local

Step 1: Edit Windows Hosts File (C:\Windows\System32\drivers\etc\hosts)

Open Notepad as Administrator and append the mapping at the bottom:

# Custom local development domain mapping
127.0.0.1       collegeweb.local
127.0.0.1       www.collegeweb.local

Step 2: Enable Virtual Hosts in Apache (httpd.conf)

Ensure the virtual hosts include line is uncommented (remove the leading #):

# Virtual hosts
Include conf/extra/httpd-vhosts.conf

Step 3: Configure Virtual Host in httpd-vhosts.conf

File path: C:/xampp/apache/conf/extra/httpd-vhosts.conf

<VirtualHost *:80>
    ServerAdmin admin@collegeweb.local
    DocumentRoot "E:/webDesigning"
    ServerName collegeweb.local
    ServerAlias www.collegeweb.local

    <Directory "E:/webDesigning">
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog "logs/collegeweb-error.log"
    CustomLog "logs/collegeweb-access.log" common
</VirtualHost>

Step 4: Restart Apache and Test

Restart Apache web server in the Control Panel and open http://collegeweb.local in your web browser.
