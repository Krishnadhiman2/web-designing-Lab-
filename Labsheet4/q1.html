Apache Web Server Verification & Setup

✓ Apache Test Page Ready

This test page verifies that your local Apache HTTP Server (via XAMPP, WAMP, or standalone Apache) is correctly configured and responding on http://localhost.

Verification Steps & Commands:

  1. Start Apache: Open XAMPP / WAMP Control Panel and click Start next to Apache (or run httpd -k start in terminal).
  2. Document Root: Place this file as index.html (or index.php) inside your web directory (e.g. C:\xampp\htdocs\).
  3. Verify in Browser: Open http://localhost or http://127.0.0.1 in your browser.

Apache Configuration Snippet (httpd.conf):

# Listen on standard HTTP port 80
Listen 80

# Server Name
ServerName localhost:80

# Document Root
DocumentRoot "C:/xampp/htdocs"
<Directory "C:/xampp/htdocs">
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>

# Directory Index default files
DirectoryIndex index.php index.html index.htm
