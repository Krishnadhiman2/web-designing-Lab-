MySQL User Privileges Configuration Guide

Principle of Least Privilege (PoLP)
Security Best Practice: Web applications should never use the root administrative account for standard database operations. Creating a dedicated application user with restricted permissions (SELECT, INSERT, UPDATE) prevents malicious queries from executing administrative commands like DROP DATABASE or altering table structures.

SQL Commands to Create User & Grant Permissions:

-- 1. Create a dedicated application user
CREATE USER 'college_app_user'@'localhost' IDENTIFIED BY 'SecureAppPass2026!';

-- 2. Grant restricted permissions on `college_db`
GRANT SELECT, INSERT, UPDATE ON college_db.* TO 'college_app_user'@'localhost';

-- 3. Flush privileges to apply changes immediately
FLUSH PRIVILEGES;

-- 4. Verify assigned permissions for the new user
SHOW GRANTS FOR 'college_app_user'@'localhost';

Updated PHP PDO Connection String:

<?php
// Connecting with the restricted database user
$host = 'localhost';
$db   = 'college_db';
$user = 'college_app_user';     // Dedicated restricted user
$pass = 'SecureAppPass2026!';   // Dedicated password

$pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass);
?>
