Apache Performance & Log Examination Guide

Apache logs all client HTTP interactions and server runtime diagnostics in its dedicated log directory (typically C:\xampp\apache\logs\).

1. Access Log (access.log)

Records every incoming HTTP request received by Apache with IP, timestamp, method, status code, and user agent.

# Sample access.log entries:
127.0.0.1 - - [12/Oct/2026:11:45:10 +0530] "GET /Labsheet4/q7.php HTTP/1.1" 200 4230
127.0.0.1 - - [12/Oct/2026:11:45:14 +0530] "POST /Labsheet4/q6.php HTTP/1.1" 200 3120
127.0.0.1 - - [12/Oct/2026:11:45:20 +0530] "GET /nonexistent-file.php HTTP/1.1" 404 196
2. Error Log (error.log)

Records server startup events, PHP fatal errors, warnings, and permission issues.

# Sample error.log entries:
[Sun Oct 12 11:40:02.124580 2026] [mpm_winnt:notice] [pid 4120:tid 680] AH00455: Apache/2.4.58 (Win64) OpenSSL/3.1.3 PHP/8.2.12 configured -- resuming normal operations
[Sun Oct 12 11:42:15.340120 2026] [php:error] [pid 4120:tid 1856] [client 127.0.0.1:51234] PHP Fatal error: Uncaught PDOException: Connection refused in ...
3. Performance Stress Testing with ApacheBench (ab):

You can benchmark server performance by simulating 100 concurrent requests:

# Command prompt:
ab -n 1000 -c 50 http://localhost/Labsheet4/q1.html
